# Changes

## November 11, 2026

- Saved Neurosift v1 links (`?p=…`) are rewritten once, when the app starts, by a tested module (`src/util/legacyUrl.ts`) that replaces the `LegacyUrlHandler` in `App.tsx`. Forms that broke before now open what they pointed to: `view:X/Y` tabs (which became an object path), `view:PSTH`, `view:RasterPlot` and `view:TrialAlignedSeries` tabs, other v1 views (opened as their object), `tab=timeseries-alignment`, `?p=/openneuro`, `?p=/openneuro-dataset`, `?p=/avi`, and `?p=/nwb&dandiAssetId=` without a url. NWB and EDF file URLs are now escaped, so a `&` or `#` inside one no longer breaks the link.
- Added the design system's foundations: design tokens (colors, type, spacing, radii and shadows) as CSS custom properties in `src/css/tokens.css`, generated by `npm run tokens` from the W3C design token files in `design-system/tokens/`, and the IBM Plex Sans JP and IBM Plex Mono fonts. Nothing uses them yet, so the app looks the same.
- Added the design system's component library in `src/ui/`, imported as `@ui`: buttons, inputs, selects, menus, tooltips, alerts and toasts, tabs, tables, trees, dialogs, sliders, time controls, legends, the catalog and object-tree pieces, and the app bar and status bar, each with unit tests. Icons are IBM Carbon SVGs built into `src/ui/Icon/icons.ts` by `npm run icons`. `design-system/migration/count.mjs` counts MUI imports, inline styles and `sx` props outside `src/ui`. Nothing uses the components yet, so the app looks the same. Button has a link variant for an action inside a sentence, an Alert's actions can show that they are working, and Playback takes the speeds and states the views need. ImageZoom wraps a picture with zoom, pan, Fit and 100%, by buttons, wheel, pinch and keys.
- Added the design system documentation site in `design-system/docs/` (Astro): foundations, tokens, usage guidelines, a page per component with live examples, and UI library pages that show each Neurosift screen as it is today and as proposed. `npm run docs:install`, then `npm run docs:dev`. The Design System workflow type-checks and builds it, runs its accessibility suite on pull requests and reports MUI imports, inline styles and `sx` props without failing, and the deploy and preview builds publish it with the app at `/design-system/` (https://neurosift.app/design-system/).
- The Settings page is rebuilt from the design system. The DANDI, DANDI sandbox and EMBER API keys are password fields with Show and Hide, each saved as it is typed, and a notice offers to reload the page so the new key is used.
- A link to a file, object or Dandiset that cannot be loaded now says what went wrong instead of showing "Loading..." forever: a missing or non-NWB file, a tab for an object the file does not have, and a Dandiset that does not exist each show an error with the cause, Try again and Report this, and an embargoed Dandiset or file (401 or 403) shows the embargo notice with Add API key.
- Errors in views, the error boundary, the embargo notice, Share and the NIfTI 4D note use the design system's Alert, Toast and Inline message. Views share one error, "… couldn't be shown", with the cause, Report this and Try again. Share copies the link and confirms with a "Link copied" toast; the DANDI and EMBER pages' two Share buttons, and their two neurodata-types panels, are now one each. The unused `NiftiViewerOld.tsx` is removed.
- The app bar is rebuilt from the design system at 48px: the Neurosift lockup, then Guide, Report a problem on GitHub, Settings, and "Open in Neurosift v1" in words where it used to be a bare "1". The status bar says what it is doing in words on one line, such as "Reading 2 groups" or "Read 19,531 groups · 1,272 datasets · 142 data requests", instead of letters and counts.
- One catalog at `/search` searches DANDI, OpenNeuro and EMBER together, and `/dandi`, `/ember` and `/openneuro` open it filtered to that archive, replacing the three archive pages. Each archive is read 25 at a time with Show more, so results are no longer capped at 50 (DANDI and EMBER) or 25 (OpenNeuro). Basic, semantic and neurodata-types search are kept (the last two search DANDI only, and the page says so), with an archive filter with counts, sorting by best match, recently modified or newest, Draft, Embargoed and Private badges, and the search kept in the address (`q`, `archive`, `mode`, `types`, `sort`). When one archive does not answer, the others still show.
- Home is rebuilt around one search across DANDI, EMBER and OpenNeuro, whose placeholder carries the live dataset count. Enter opens the catalog, and a pasted link opens like Open a file by link. Browse all datasets and Browse DANDI datasets open the catalog newest first. Open a file by link takes NWB, LINDI, Zarr and DANDI asset links and dataset page links, and says what Neurosift opens when it gets something else. Recently opened lists up to five datasets from any archive in one list, and older entries carry over. The footer links the NWB viewer guide, Neurosift Chat, the source on GitHub and Report a problem, and shows the version.
- The NWB viewer guide at `/guide` is rebuilt from the design system, word for word as before, with its commands in code blocks with Copy; `guide.md` is removed.
- The DANDI, EMBER and OpenNeuro dataset pages share one overview built from the design system: breadcrumbs back to that archive's search (OpenNeuro had none), the version, facts as a description list (Created, Modified, Status, Size, Files, Subjects, and for OpenNeuro Views and Downloads), long descriptions and contributor lists behind Show full, keywords and modalities as tags, and DANDI's Subjects, which had been dropped. The file list is a tree with Download for the selected file, Show NWB files only and a count beside Load more files; open files are tabs, and a file Neurosift cannot show offers Download the file. The DANDI page's Chat link, which went to dandiset-explorer.vercel.app (404), now opens the Dandiset explorer chat at dandiset-explorer.neurosift.app for that Dandiset.
- The NWB file page is rebuilt from the design system. A breadcrumb row reads archive › Dandiset › folders › file. The overview is a side panel with Dandiset and Session details, the version as a select, and the description and contributors behind Show more; it opens at 320px, can be dragged between 240 and 480px or resized by keyboard, collapses, and remembers its width and state. Section and object tabs are design-system tabs with Schema and HDF5 at the end, and each object shows its neurodata type and path with Copy path and Copy link. The splitter layout is replaced by a flex layout.
- The object tree on an NWB file's Main tab is rebuilt from the design system, with its data loading unchanged. Each row shows a chevron, checkbox, type icon, name, neurodata type and, on the same line, the description, cut with an ellipsis and shown in full on hover; view options sit below as chips. Clicking an object's name opens it (before, only the ⧉ beside it did), and a view chip's name opens that view. "View N selected" becomes a selection bar that names what is checked, with Clear and View together.
- The HDF5 tab is rebuilt from the design system: a tree of groups and datasets with type, shape and item counts, a find box that keeps parents (the first search reads every group, up to 5,000), and a details panel with Copy path, the dataset's type, shape, chunks and compression, its attributes, and its values (ten or fewer directly, larger datasets with Show first 10 rows). It replaces the unlabeled circle that logged every value to the console. The Schema tab gets a find box, All types or Used in this file, Namespaces and Types tables, and a details panel with a type's inheritance, datasets, groups, attributes and where the file uses it; hdmf-common types are now named from `data_type_def`. The unused `TopLevelGroupContentPanel`, `ExpandableTableCell` and their CSS files are removed.
- The viewers inside a dataset's file tab are rebuilt from the design system. Every file shows its path, size, ID and URL, with Copy and a Download button per mirror. NIfTI asks before loading a large file ("Load this 5.4 MB file?"; the 100 MB and 2,000 MB limits are unchanged) and its controls are a select, checkboxes and Previous and Next frame buttons. TSV files are a sortable table with Copy table; JSON and text are wrapped and cut at 200 lines behind Show all; audio shows sample rate, channels and length with play, pause and back to start. The unused `ProgressBar.tsx` and MUI `Table.tsx` are removed.
- The time series views (traces, Events, BehavioralEvents, IntervalSeries and TimeIntervals) share one frame from the design system, with the charts themselves unchanged: a view panel with a one-line summary such as "0.00–1,375.69 s · 400 Hz · 70 channels", a Time window and a Time overview on the shared time selection. Traces get a Channel window, a Separation slider and a labeled Canvas or Plotly switch in place of the unlabeled "." button. Too much data is a warning with Zoom in and Draw anyway instead of a red sentence. In TimeIntervals, Label by is a select and the renderer is a segmented control. The Spatial Series X/Y view and the EDF viewer (`/edf` and EDF files in OpenNeuro datasets) use the same frame, the traces, Spatial X/Y, two-photon and EDF views get Play with a speed, which moves the time window and waits for data instead of skipping ahead, and a window too long to draw shows Zoom in and Draw anyway in Spatial X/Y too. The intracellular ephys (Icephys) tab is rebuilt as a view panel with its settings in accordion items, with its plots and settings unchanged.

## October 21, 2026

- Removed annotations: the Annotations page, the annotation panels on dandiset, NWB and OpenNeuro pages, the home page's highlighted views, and the notebook and chat links built from annotations. They had not been used since mid-2025, and depended on the `neurosift-annotation-manager` service.
- Removed Neurosift jobs: the job manager client, the Neurosift API key and admin user management in Settings, and the views that only ran as jobs (MP4 Video for ImageSeries, Spike Density, which was already switched off, and the text letter-count demo). They depended on the `neurosift-job-manager` service and were unused. Figpack views, which use their own service, are unchanged.
## October 22, 2026

- Neurodata-types search on the DANDI and Ember pages uses an index built from the DANDI index and served by the DANDI-index job runner (`/api/neurodata-types-index`), refreshed nightly. The previous file at lindi.neurosift.org had not been updated since July 2025. It now covers 606 dandisets (was 408) and up to 200 files per dandiset (was 100); table-column types such as `VectorData` and `ElementIdentifiers` are no longer listed.

## October 13, 2026

- The Spectrogram view is now offered for any ElectricalSeries whose own name or containing group's name mentions LFP (or an uppercase "LF" or a `.lf` suffix, as in SpikeGLX LF streams), not only for objects under an "LFP" processing module. This covers acquired LFP such as iEEG stored outside `/processing`.
- zarrshadow, the package that writes the Zarr reference files Neurosift opens, is now called shadowzarr. Reference files named `.shadowzarr` or `.shadowzarr.json` are recognized, and so are files named `.zarrshadow` before the rename.

## October 12, 2026

- The DANDI-index job runner's `findDandisets({ semanticSearch })` ranks dandisets with the index's own embeddings, the same way as `semanticSortDandisets`, instead of calling the `neurosift-chat-agent-tools` Vercel service. It returns the top 20 and still honors `restrictToDandisets`.
- The NWB, dandiset, OpenNeuro dataset, SLP and video pages load about 63 kB less JavaScript: the Zarr reader is now fetched only when a Zarr file is opened.
- Browsers now revalidate the app's JavaScript chunks on each load. A chunk requested in the moments after a deploy could be answered with `index.html`, which browsers then reused for up to 4 hours, so the page that needed it failed to load until then.

## October 11, 2026

- DANDI semantic search on the DANDI page now queries the CatalystNeuro-hosted index service (`dandi-index.catalystneuro.com`) instead of the `neurosift-search` Vercel proxy, which is being retired.

## October 8, 2026

- Fixed the OpenNeuro dataset page and the OpenNeuro browser, which both failed to load after OpenNeuro changed its GraphQL API. Dataset file queries no longer ask for the removed `key` field, and dataset search uses the new `DatasetSearchInput` format. The same search fix is applied to the chat agent's OpenNeuro search tool.
- Pages and views now load on demand. The app used to ship as a single 8.6 MB JavaScript file that every page downloaded. Each page is now its own chunk, NWB and dataset file views load when they are opened, and Plotly, the NIfTI viewer, and the Blosc decoder load the first time they are needed. The home page downloads about 0.4 MB and the NWB page about 0.9 MB before rendering.
- A tab left open across a deploy reloads itself when it asks for a chunk from the previous build.
- An error in one view no longer blanks the whole app. Each page, each NWB tab and view, and each dataset file view is now inside an error boundary that shows the error in place with a "Try again" button and a "Report this" link, which opens a GitHub issue with the page URL and the error filled in.
- Errors are sent to the logging endpoint: render errors caught by a boundary, uncaught errors, and unhandled promise rejections. Each distinct error is sent once per page load, and presigned URL signatures are removed from the logged page URL.
- NWB files stored as Zarr can be opened by url. A Zarr store written by hdmf-zarr is read through its consolidated metadata, both Zarr v2, which every NWB Zarr asset on DANDI is today, and Zarr v3. A [zarrshadow](https://github.com/bendichter/zarrshadow) reference file for an HDF5 NWB file is read the same way, with range requests into the original file. Datasets that older versions of hdmf-zarr stored as Python pickles, and compound datasets of Zarr v2 stores, are listed but not read. Opening a Zarr asset from a dandiset's file list is not part of this change.

## October 6, 2026

- The DANDI-index job runner and index builders can get embeddings from another OpenAI-compatible provider that serves `text-embedding-3-large`, such as OpenRouter, by setting `OPENAI_BASE_URL` and `OPENAI_EMBEDDING_MODEL`. Defaults are unchanged.

## September 25, 2026

- DANDI semantic search now ranks dandisets by an embedding of all their searchable metadata (title, description, keywords, species, anatomy, approaches, measurement techniques, measured variables, contributors, funders, and related resources), so queries that combine a topic with a species or method, like "rat hippocampus tetrode recordings", return matching datasets.
- Fixed the DANDI-index job runner's script sandbox, which made every interface call other than `print` hang until the time limit. The interface now runs inside the sandbox with read access to the index data only.
- The job runner can serve HTTP (`HTTP_PORT`) with the same endpoints as neurosift-search, so clients no longer need PubNub. PubNub is now optional.

## September 4, 2026

- Released neurosift 0.2.16 on PyPI. The local file server started by `neurosift view-nwb` no longer exits on a request for a forbidden path or a directory, handles byte ranges correctly (clamped ranges, suffix ranges, 416 for unsatisfiable ones), answers HEAD requests, and listens on localhost only. `view-nwb` refuses zarr directories with a clear message and installs the server's npm dependencies only once.
